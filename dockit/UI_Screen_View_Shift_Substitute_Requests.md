### [UC-SHIFT-07] [View Shift Substitute Requests]

**Function trigger:** The Coordinator selects the shift substitute requests option from the system navigation menu or accesses the shift requests page.

**Function description:** This screen displays the list of shift substitute requests submitted by security guards, including substitution reasons, requested shift details, and current request status.

**Screen layout:**

**Function Details:**

*   **Normal execution case:**
    *   The Coordinator accesses the shift substitute requests page.
    *   The system displays the list of substitute requests, including requester guard information, submission date, substitution reason, requested shift details, and current status.
    *   The Coordinator views the shift substitute requests and their details.

*   **Abnormal execution case:**
    *   If no substitute requests exist, the system displays an empty notice indicating no requests are available.
    *   If an error occurs while retrieving data, the system displays an error notification.
