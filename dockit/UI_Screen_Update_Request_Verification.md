### 4.1.6 Update Request Verification

**Function trigger:** The Coordinator enters site description details or uploads survey photos on the "Báo Cáo Khảo Sát Yêu Cầu" page and clicks "Cập nhật thông tin khảo sát".

**Function description:** This screen action allows Coordinators to record physical site conditions and attach survey photos for Admin review.

**Screen layout:**
[*(Để trống khu vực này để người dùng chèn ảnh mockup)*]

**Function Details:**

*   **Normal execution case:**
    *   The Coordinator enters text into "MÔ TẢ HIỆN TRẠNG" and uploads images in "HÌNH ÁNH KHẢO SÁT".
    *   The Coordinator clicks "✓ Cập nhật thông tin khảo sát".
    *   The system uploads images to storage, saves report data, and displays a success notification.

*   **Abnormal execution case:**
    *   If image upload or save operation fails, the system displays an error banner ("Lỗi khi upload ảnh." or "Lỗi cập nhật khảo sát.").
