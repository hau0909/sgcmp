### [UC-GUARD-06] [View Personal Guard Profile]

**Function trigger:** The Guard selects the profile menu option or navigates to the profile page.

**Function description:** This screen displays the personal profile information, identity document records, physical attributes, professional skills, health certificate, skill certificates, and profile approval status of the security guard.

**Screen layout:**
[*(Để trống khu vực này để người dùng chèn ảnh mockup, hoặc chèn cú pháp ảnh Markdown nếu có sẵn link: `![Tên ảnh](url)`)*]

**Function Details:**

*   **Normal execution case:**
    *   The Guard accesses the personal profile page.
    *   The system displays the Guard's profile details, including account information, personal details, identity records (CCCD/CMND), physical attributes, professional skills, health certificate, skill certificates, and current approval status.
    *   The Guard views their profile information and attached certificates.

*   **Abnormal execution case:**
    *   If profile information is unavailable, the system displays a notice indicating profile information could not be found.
    *   If an error occurs while loading data, the system displays an error notification.
